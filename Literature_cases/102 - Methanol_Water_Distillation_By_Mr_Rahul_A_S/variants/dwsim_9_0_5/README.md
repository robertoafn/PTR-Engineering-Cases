# Variantes DWSIM 9.0.5 - pendientes del usuario

Esta carpeta no contiene todavía una simulación. El baseline FOSSEE ubicado en
la raíz del caso es inmutable.

Orden obligatorio:

1. `parity_raoult/`: copia abierta, guardada y resuelta con DWSIM 9.0.5 sin
   cambiar deliberadamente especificaciones ni paquete;
2. `alternative_models/nrtl/`: variante separada con parámetros y fuente
   documentados;
3. otras variantes sólo si existe una pregunta científica y criterio de
   comparación explícitos.

Cada archivo nuevo debe tener nombre inequívoco, checksum, metadata, resultados
exportados y un informe que compare contra el baseline.
