# Insumos de literatura pendientes

No se versionan parámetros DECHEMA, rangos de U ni datos VLE porque las
referencias `[[12]]`, `[[16]]` y `[[39]]` entregadas en las instrucciones
no resuelven una fuente, edición, página, convención, licencia y dominio
experimental verificables.

Los scripts de validación cruzada aceptan insumos externos sólo cuando incluyen
el contrato mínimo documentado por su CLI. Hasta entonces, los criterios
correspondientes permanecen `NOT_RUN`; no se sustituyen con valores
inventados.
